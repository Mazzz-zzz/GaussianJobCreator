# GaussianJobCreator

Scripts to generate and batch-submit Gaussian 16 jobs on an HPC cluster (SLURM).

- `ADMP_decomposition_gaussian/` — ADMP molecular dynamics inputs for studying thermal decomposition at a range of temperatures
- `barrier_energy_guassian/` — barrier energy calculation inputs
- `generate_orbitals_from_ADMP/` — orbital calculations from ADMP trajectory geometries
- `generate_orbitals_from_kinbot/` — orbital calculations from KinBot IRC geometries

See each directory's README for usage.
